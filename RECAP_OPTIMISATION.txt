  🎯 ÉTAPES POUR UTILISER LES FICHIERS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ┌───────────────────────────────────────────────────────────────────────┐
  │  ÉTAPE 1 : CONVERTIR LES IMAGES EN WEBP  ⚠️ TRÈS IMPORTANT           │
  ├───────────────────────────────────────────────────────────────────────┤
  │  1. Double-cliquez sur "convert-to-webp.bat"                          │
  │  2. OU utilisez CloudConvert : https://cloudconvert.com/jpg-to-webp   │
  │  3. Convertissez TOUTES les images du dossier assets/                 │
  │                                                                        │
  │  Images à convertir :                                                 │
  │  • img1.jpg         → img1.webp                                       │
  │  • img2.jpg         → img2.webp                                       │
  │  • img3.jpg         → img3.webp                                       │
  │  • img-real-1.jpg   → img-real-1.webp                                 │
  │  • img-real-2.jpg   → img-real-2.webp                                 │
  │  • img-real-3.jpg   → img-real-3.webp                                 │
  │  • logo.jpg         → logo.webp                                       │
  │  • logo-footer.png  → logo-footer.webp                                │
  │  • logo-cqp.jpg     → logo-cqp.webp                                   │
  │  • logo-qb46.JPG    → logo-qb46.webp                                  │
  └───────────────────────────────────────────────────────────────────────┘

  ┌───────────────────────────────────────────────────────────────────────┐
  │  ÉTAPE 2 : RENOMMER LES FICHIERS                                      │
  ├───────────────────────────────────────────────────────────────────────┤
  │  1. Renommer index.html → index-old.html (backup)                     │
  │  2. Renommer index-optimized.html → index.html                        │
  │  3. Renommer styles.css → styles-old.css (backup)                     │
  │  4. Renommer styles-optimized.css → styles.css                        │
  └───────────────────────────────────────────────────────────────────────┘

  ┌───────────────────────────────────────────────────────────────────────┐
  │  ÉTAPE 3 : TESTER EN LOCAL                                            │
  ├───────────────────────────────────────────────────────────────────────┤
  │  1. Ouvrir index.html dans Chrome                                     │
  │  2. Vérifier que tout fonctionne (menu, images, boutons)              │
  │  3. F12 → Lighthouse → Analyser                                       │
  │  4. Vérifier scores ≥ 95 dans toutes catégories                       │
  └───────────────────────────────────────────────────────────────────────┘

  ┌───────────────────────────────────────────────────────────────────────┐
  │  ÉTAPE 4 : DÉPLOYER SUR LE SERVEUR                                    │
  ├───────────────────────────────────────────────────────────────────────┤
  │  1. Uploader index.html (nouveau)                                     │
  │  2. Uploader styles.css (nouveau)                                     │
  │  3. Uploader .htaccess (mis à jour)                                   │
  │  4. Uploader toutes les images WebP dans assets/                      │
  │  5. Tester à nouveau avec Lighthouse                                  │
  └───────────────────────────────────────────────────────────────────────┘

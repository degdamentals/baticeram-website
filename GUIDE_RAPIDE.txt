📋 ÉTAPES POUR UTILISER LES FICHIERS OPTIMISÉS
────────────────────────────────────────────────────────────────

ÉTAPE 1 : CONVERTIR LES IMAGES EN WEBP (TRÈS IMPORTANT !)
──────────────────────────────────────────────────────────
Les images WebP sont 30% plus légères que JPG/PNG.

Option A - Avec le script automatique (RECOMMANDÉ) :
  1. Double-cliquez sur "convert-to-webp.bat"
  2. Si cwebp n'est pas installé, téléchargez-le :
     → https://developers.google.com/speed/webp/download
     → Extrayez le ZIP
     → Ajoutez le dossier "bin" au PATH Windows
  3. Relancez le script

Option B - En ligne (plus simple) :
  1. Allez sur https://cloudconvert.com/jpg-to-webp
  2. Uploadez vos images du dossier "assets"
  3. Convertissez (qualité : 85-90%)
  4. Téléchargez et remplacez dans "assets/"

Images à convertir :
  - img1.jpg
  - img2.jpg
  - img3.jpg
  - img-real-1.jpg
  - img-real-2.jpg
  - img-real-3.jpg
  - logo.jpg
  - logo-footer.png
  - logo-cqp.jpg
  - logo-qb46.JPG


ÉTAPE 2 : RENOMMER LES FICHIERS OPTIMISÉS
──────────────────────────────────────────
Sauvegardez d'abord les originaux, puis renommez :

1. Renommer index.html en index-old.html (backup)
2. Renommer index-optimized.html en index.html

3. Renommer styles.css en styles-old.css (backup)
4. Renommer styles-optimized.css en styles.css


ÉTAPE 3 : TESTER EN LOCAL
──────────────────────────
1. Ouvrez index.html dans votre navigateur
2. Vérifiez que tout fonctionne :
   ✓ Menu de navigation
   ✓ Images qui s'affichent
   ✓ Animations au scroll
   ✓ Menu mobile (rétrécissez la fenêtre)
   ✓ Boutons "Nous contacter"


ÉTAPE 4 : TESTER AVEC LIGHTHOUSE
─────────────────────────────────
1. Ouvrez Chrome
2. Appuyez sur F12 (DevTools)
3. Allez dans l'onglet "Lighthouse"
4. Cochez : Performance, Accessibility, Best Practices, SEO
5. Mode : Navigation (Desktop ou Mobile)
6. Cliquez "Analyze page load"

SCORES ATTENDUS :
  ✅ Performance     : 90-100 (avec WebP)
  ✅ Accessibilité   : 95-100
  ✅ Bonnes Pratiques: 95-100
  ✅ SEO             : 95-100


ÉTAPE 5 : DÉPLOYER SUR LE SERVEUR
──────────────────────────────────
1. Uploadez TOUS les fichiers via FTP :
   - index.html (nouveau)
   - styles.css (nouveau)
   - .htaccess (mis à jour)
   - Toutes les images WebP dans assets/

2. Vérifiez que le .htaccess fonctionne :
   - Compression GZIP active
   - Cache navigateur actif

3. Testez à nouveau avec Lighthouse sur le site en ligne

═══════════════════════════════════════════════════════════════
  RÉSOLUTION DE PROBLÈMES
═══════════════════════════════════════════════════════════════

❌ Les images WebP ne s'affichent pas
  → Vérifiez que les fichiers .webp existent dans assets/
  → Vérifiez que le navigateur supporte WebP (Chrome, Edge, Firefox oui)
  → Les balises <picture> incluent un fallback JPG/PNG

❌ Le cache ne fonctionne pas
  → Vérifiez que mod_expires est activé sur Apache
  → Vérifiez que mod_headers est activé sur Apache
  → Videz le cache du navigateur (Ctrl+Shift+Delete)

❌ Le score Lighthouse est toujours bas
  → Assurez-vous d'avoir converti TOUTES les images en WebP
  → Videz le cache et relancez le test
  → Testez en navigation privée
  → Désactivez les extensions Chrome

❌ Le menu mobile ne fonctionne pas
  → Vérifiez la console JavaScript (F12)
  → Le script doit être chargé avec defer
  → Vérifiez que tous les ID sont corrects


═══════════════════════════════════════════════════════════════
  AMÉLIORATIONS FUTURES (OPTIONNELLES)
═══════════════════════════════════════════════════════════════

🔒 HTTPS
  → Installez un certificat SSL (Let's Encrypt gratuit)
  → Décommentez les lignes HTTPS dans .htaccess
  → Gain : +5-10 points SEO/Sécurité

📦 CDN (Content Delivery Network)
  → Cloudflare (gratuit) : https://www.cloudflare.com
  → Améliore les temps de chargement mondiaux
  → Gain : +10-15 points Performance

⚙️ HTTP/2 ou HTTP/3
  → Demandez à votre hébergeur d'activer HTTP/2
  → Multiplex les requêtes pour un chargement plus rapide
  → Gain : +5-10 points Performance

🗜️ Minification CSS/JS
  → Utilisez cssnano pour CSS
  → Utilisez UglifyJS pour JavaScript
  → Gain : +3-5 points Performance
